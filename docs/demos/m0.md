# M0 demo: scaffold and Copilot spike

```powershell
pnpm install
pnpm -r typecheck && pnpm -r test && pnpm -r build   # all green
cd examples/sample-target && npx vitest run            # 3 failing tests, by design
cd ../..
pnpm orca auth status                                   # "not signed in" until login
pnpm orca auth login                                    # browser OAuth flow via the official Copilot CLI; GitHub asks for 2FA (sudo mode); listener times out after ~5 min
pnpm orca auth status                                   # "signed in as <login> (user, github.com)"
pnpm orca models                                        # models allowed by your Copilot policy
pnpm --filter @orca/engine spike                        # one real agent turn; prints events and permission requests
pnpm dev                                                # engine + UI; browser shows engine, auth, and model status
```
