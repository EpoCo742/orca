# M1 demo: vertical slice, "fix until green"

Prerequisites: M0 done (`pnpm orca auth status` says signed in).

## Headless

```powershell
pnpm orca run fix-until-green-fake        # engine smoke test, no model calls: 2 iterations, exits "until"
pnpm orca run fix-until-green --approve-all   # real Copilot agent (claude-sonnet-5): ~12 s, ~4-5 premium requests
```

Expected tail of the output:

```
  @ loop exit (until) after 2
  + loop completed last={"test":{"exit_code":0, ...}} iterations=2 exited_by=until
  + verdict completed value=true
  + summary completed value={"green":true,"iterations":2,"exitedBy":"until", ...}
  run.completed
run completed  premium requests: 4
```

## In the browser

```powershell
pnpm dev            # engine on 127.0.0.1:4111, UI on 127.0.0.1:5173, opens the browser with the token in the URL hash
```

1. Sidebar > Templates > "Fix until green" registers the template in place and opens it on the canvas: `start -> reset -> loop { test -> failing? -> fix } -> verdict -> summary`.
2. Click **Run**. The canvas switches to Run mode; nodes light up as they start, complete, or get skipped; the loop shows the current iteration.
3. Click the `fix` node: iteration tabs (`loop[0]`, `loop[1]`), status, cost in premium requests, outputs, and the Transcript tab with the agent's messages, tool calls, results, and policy decisions.
4. Approvals: when an agent asks for a tool the node's allow list does not cover, a card appears at the top with the exact command. Allow once, allow for this run (adds a rule for the rest of the run), or deny with a comment. Decisions are recorded on the run.
5. Crash-resume: while a run is in flight, kill the engine and run `pnpm dev` again. The log shows `resuming run after restart`; completed nodes are not re-run, the in-flight node restarts as attempt 2, and the run completes.

## What was verified on 2026-09-10

- 30 engine tests (schemas, sandbox, permissions, scheduler: loops, conditional skips, error edges, retries, approvals, cancellation, crash-resume, fake template end to end).
- Real Copilot run from CLI and from the UI: agent fixed `divide` and `average`, 4 tool calls, 4-5 premium requests, loop exited via `until` after 2 iterations.
- Approval card via WebSocket, approved from the UI, run continued.
- Engine killed mid-run and restarted: run resumed and completed with memoized upstream nodes.
